# fulfenlabs.io

The public website of Fulfen Labs, a forward deployed engineering practice: five static pages (home, how we work,
team, handbook, contact) on GitHub Pages at [fulfenlabs.io](https://fulfenlabs.io/) (`CNAME`).

- `index.html`, `method/`, `team/`, `handbook/` and `style.css` are generated; edit the generator, not the pages.
- `img/team/` holds 480 px headshots of the AI team, each checked before it is published.
- The Fulfen Labs team are AI characters, except Daniel Vaughan; every page says so. No clients, testimonials or
  figures are shown unless they are real and permitted.
- No analytics, cookies or forms. The gitleaks pre-commit hook scans each commit: run `pre-commit install` once.
